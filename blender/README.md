# Clothing Skeleton Bridge 0.7.0

FFXIV 服装骨架工作台的配套 Blender 插件。游戏和 Blender 两侧必须一起更新至 0.7。

安装同版本 ZIP 并启用 Clothing Skeleton Bridge。3D 视图按 N → 服装骨架 → 连接游戏，默认本机端口 43867。游戏读取自己或当前目标、选择 Mod 和发送内容后，模型与骨架加入当前场景，不会清空工程。

不同装备使用独立集合和独立骨架；人物与头部、穿着装备、武器参考各自成组。每套工作骨架内再分人物骨骼、服装原骨和服装骨骼三个集合。只编辑新增骨骼，用 Shift+A/E 创建并手动指定父级。误放集合可点击“整理新增服装骨骼”。

导入自己的服装后，选“网格归属部件”，选中网格并点击“将所选网格加入服装”。确保 UV、材质槽和权重正确。选择仅骨骼或完整服装＋骨骼，然后点击发送。游戏按 Mod 保存 glTF、MDL 和确有新增骨骼时的 SKLB。共享游戏骨架资源只在导出阶段临时汇总新链，场景工作骨架保持独立。

人物骨架从所选角色对应的原版资源导出；不使用人物 Mod 骨架。参考模型采用当前已加载资源，以制作姿态显示，暂不发送贴图。模型回传沿用目标装备材质路径；贴图、游戏材质、权重制作、动画和物理不自动生成。

保持两侧连接，同一时间只连接一个 Blender。收到项目时若正在编辑，会等回到对象模式再导入。重复发送相同内容保留现有修改。请自行保存 .blend；游戏返回位置及 Blender 缓存均自动管理。
