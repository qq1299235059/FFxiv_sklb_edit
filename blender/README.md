# Clothing Skeleton Bridge 0.6.1

这是 FFXIV 服装骨架工作台配套的 Blender 插件。通过本机端口连接游戏，将骨架直接加入当前工程，不启动新 Blender、不清空现有对象。

## 安装和连接

在 Blender 4.5 的“偏好设置 → 插件 → 从磁盘安装”中安装同版本 `ClothingSkeleton-Blender-0.6.1.zip`，启用 Clothing Skeleton Bridge。更新后停用再启用。

按 N 打开 3D 视图右侧“服装骨架”面板，默认自动连接游戏。默认本机端口 43867，仅连接 127.0.0.1。端口被占用时，在游戏指引与 Blender 面板设置相同的其他端口，分别应用并连接。无需 Blender 程序地址或返回路径。一次只连接一个 Blender。

## 编辑与返回

在游戏读取自己或当前目标，选择匹配的服装骨架，点击“创建并发送到 Blender”。原版人物挂点与服装原骨位于同一骨架。

按 Tab 进入编辑模式，用 Shift+A 添加、E 挤出骨链。已有新链先选第一根，Shift 最后选目标父骨，再 Ctrl+P → 保持偏移。只编辑新增骨骼。返回时自动忽略未用挂点，场景保留完整挂点。当前格式最多 4 个实际连接，原装备已有连接计入。

点击“返回游戏”，等待面板显示“已返回游戏”，再到游戏“回导并检查”。游戏侧固定保存 `BlenderReturn/edited.gltf`，Blender 仅使用自己的本机缓存，不依赖游戏安装目录。

重复发送同一项目保留已有编辑；新项目新增骨架对象。收到新项目时若处于编辑模式或模态操作，会等待回到对象模式后导入。请自行保存 `.blend` 工程。

人物骨架来自游戏选择的角色对应原版文件，不使用预设或人物 Mod 骨架。工具不独立转换 SKLB，不自动生成服装权重、动画或物理。

[完整安装与使用说明](https://github.com/qq1299235059/FFxiv_sklb_edit)

## 骨骼集合与状态检查

面板使用三个集合：**人物骨骼**（原版人体挂点）、**服装原骨**（受保护的装备原骨）、**服装骨骼**（用户新增的自定义骨骼）。可以分别切换显示，也可在 Blender 骨架数据属性中查看集合。

原生 Shift+A、E、Shift+D 创建的新骨会自动分配独立身份并归入服装骨骼；不再提供两个预制添加按钮。已有骨骼手动放错集合时会保留错误状态供检查。点击 **整理新增服装骨骼** 将全部新增服装骨骼归入正确集合，并移出人物及服装原骨集合；父级、静止姿态和编辑模式保持，操作可撤销。

状态检查会对照导入时的原版人物骨骼，检查缺失、改名、父级、静止姿态及集合归属。新骨挂在手腕等人物骨骼下是正常的；新骨进入人物集合，或者人物原骨被改为服装新骨的子级，会显示提醒和错误。有错误时禁止返回，也会在导出时再次检查。集合错误可一键整理；原骨被修改则需要撤销或恢复。

0.6 已接收的骨架可以在连接后由游戏重发同一项目以补充人物对照资料，已有编辑会保留。缺少对照资料时面板会提示重新发送。
