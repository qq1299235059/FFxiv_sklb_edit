# FFXIV 服装自定义骨骼插件规划资料

本项目面向国服 FFXIV 的服装替换 Mod 制作。目标是在 Dalamud 面板选择服装使用的 SKLB，送入 Blender 添加自定义骨骼，再回导、校验，并通过 Penumbra 安装与预览。

建议采用 **Dalamud 插件加轻量 Blender 插件**，以 **glTF 2.0 加项目元数据** 进行交换。先完成上衣附加骨架的追加骨骼流程，再扩展其他适用部位。服装最终使用新增骨骼，还需要匹配的 MDL 骨骼表与权重、EST 附加骨架配置，以及正确的骨架映射。新建骨骼不会自动产生布料物理或专用动画。

资料日期：2026 年 10 月 8 日。文档中的架构、规则和里程碑是项目设计；所引上游代码证明已有相关实现，不代表已在当前国服客户端完成往返或加载测试。

## 已确定的项目决策

1. 用途是给服装 Mod 添加骨骼，目标客户端是国服。
2. 优先走服装附加骨架，首个样例建议选上衣。基础角色骨架作为对齐参考，保留其身份与原始结构。
3. 原骨骼保持名称、索引和结构；新骨骼追加。骨架 mapper 与连接信息需要作为独立工作处理，不能靠追加数组自动解决。
4. glTF 是 Blender 和现有 FFXIV 工具之间的交换载体；原始 SKLB 与配套元数据保留游戏专属信息。
5. 第一版利用已有模型制作工具完成服装 MDL 和权重回导。本插件负责骨架转换、关联检查、部署计划和预览，不假设 Penumbra 有通用 MDL 转换 IPC。
6. 第一版验收目标是新增骨骼参与服装蒙皮并随有效父骨运动。物理摆动、独立动画和跨种族自动适配另设阶段。

## 进入开发阶段后的第一个样例

选定一个国服角色、一个上衣替换 Mod、一套确实被该装备加载的附加 SKLB，以及对应的服装 MDL。先做未编辑往返，再在服装骨架追加一根独特命名的骨骼，把一小片测试网格完全绑定到它，回导 MDL 与 SKLB，设置必要的 EST，重绘目标角色并验证运动和回滚。

这一样例通过后，才将流程推广到实际裙摆、飘带或装饰件骨骼链。
